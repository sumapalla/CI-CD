#  CI/CD Pipeline using Jenkins, Docker, Kubernetes & Argo CD

## 📌 Project Overview

This project demonstrates an end-to-end CI/CD pipeline that automates the build, testing, containerization, and deployment of an application using DevOps tools.

---

## 🛠️ Technologies Used

- Git & GitHub
- Jenkins
- Maven
- SonarQube
- Docker
- Docker Hub
- Kubernetes (Minikube)
- Argo CD
- Java Application

---
## 🏗️ Architecture

Developer
↓
GitHub Repository
↓
Jenkins Pipeline
↓
Maven Build
↓
SonarQube Code Analysis
↓
Docker Image Build
↓
Docker Hub
↓
Kubernetes Deployment
↓
Argo CD Sync
↓
Application Running
